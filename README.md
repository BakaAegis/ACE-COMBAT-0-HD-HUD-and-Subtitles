## 本版内容

- 保留当前已经测试的高清汉化、HUD 布局、字体、泛光和机炮增强，不重新调整视觉或判定参数。

## 安装与升级

将整个 AC0-HD-v2-r2 文件夹放在含 acz.exe、a.arc、d.arc 的 ACZero 目录，或其直接上一级启动器目录。完整退出目标游戏和启动器后运行 Install.bat，按中文菜单选择安装或卸载。

缺少 settings/setting.ini 时，请按原方式启动一次并进入菜单，再完整退出。若已有配置中的 `SystemLanguage=` 为空（包括其后只有空格、制表符或 `;JP US UK DE FR IT ES` 注释），安装器会自动识别默认语言状态。安装高清汉化与 HUD 时仅将该值设为 JP；卸载时恢复原来的空值，并保留注释、空白和其他设置。仅安装或卸载机炮不会改变语言。缺失、重复或格式异常的语言项仍会拒绝，不复制别人的 setting.ini。中文资源使用 JP 语言槽，安装时仅调整语言项。

卸载会保留另一组件、共享加载器、管理器、备份和事务日志；它不是彻底清理所有 MOD 文件。历史源码和组件内文档保留原版本语境，本版支持范围以根目录说明和严格的运行时清单为准。
